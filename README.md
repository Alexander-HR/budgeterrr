# Feedback and contributions
Ay we welcome any feedback in the form of issues (https://github.com/Alexander-HR/budgeterrr/issues), but ask that before posting a new issue you search some keywords to check if your issue already exists and then you can upvote that issue instead.

If you can implement solutions to existing issues then please fork the repo, implement the solution on branch dedicated to that issue and then file a pull request (PR). It is most appreciated and probably doubles the dobloon protection possibilities of fellow budgeteerrrs.
