## Personal financial data

This repo is public. Never commit bank statements (`.xlsx`, `.xls`, `.csv`), database files (`.db`, `.sqlite*`), or anything under `fixtures/private/`, and never paste real transaction data into code, tests, issues, or commit messages. Real exports go in `fixtures/private/` (gitignored) for local reference only. Test fixtures must be synthetic and generated by test code, not checked-in spreadsheet files.
